Menú de Tests & Rendimiento

Ejecuta pruebas reales sobre el hardware, base de datos, disco y conectividad del VPS.

1. Test de Base de Datos (I/O & Queries)

Inserta 500 registros en lote en la base de datos SQLite montada en el volumen, ejecuta consultas de agregación y mide las transacciones por segundo.

2. Test de Velocidad de Disco (Volumen)

Escribe un bloque binario de 25 MB en el volumen de almacenamiento del VPS, sincroniza con fsync, lee el bloque y calcula la velocidad en MB/s.

3. Test de Red, Salida a Internet e IP Pública

Comprueba la resolución DNS, mide la latencia de solicitud HTTP hacia el exterior y consulta la IP pública del servidor VPS.

4. Test de Rendimiento de CPU

Ejecuta un ciclo matemático intensivo de 3 segundos para medir el número de iteraciones por segundo del núcleo asignado en el VPS.

Guía de Despliegue en tu VPS

Pasos sencillos para montar esta aplicación en cualquier servidor VPS (Ubuntu, Debian, etc.).

1

Instalar Docker y Docker Compose en el VPS (si no lo tienes)

curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
2

Subir o Clonar este Proyecto

Copia la carpeta a tu VPS o clónala desde tu repositorio git:

git clone <TU_REPOSITORIO> vps-tester
cd vps-tester
3

Lanzar con Docker Compose (Un solo comando)

Crea los volúmenes persistentes y arranca la interfaz y la base de datos automáticamente:

docker compose up -d --build
4

Acceder desde tu navegador

Abre en tu navegador web la IP de tu VPS en el puerto configurado (por defecto 8000 o 80):

http://<IP_DE_TU_VPS>:8000
